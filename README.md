# OS-Level Task Priority Scheduler

An educational operating-system scheduling simulator developed
as a Data Structures laboratory project.

## Objectives

- Implement custom data structures.
- Simulate priority-based CPU scheduling.
- Support preemptive scheduling and MLFQ.
- Demonstrate deadlock detection and avoidance.
- Demonstrate priority inversion and priority inheritance.
- Implement Rate Monotonic Scheduling.
- Compare scheduling algorithms using performance metrics.

## Technology Stack

- Backend: C++
- Build system: CMake
- Frontend: Pending team approval
- Version control: Git and GitHub

## Project Structure

- `backend/`: C++ simulation engine and algorithms
- `frontend/`: User interface, if approved
- `docs/`: Architecture and project documentation
- `examples/`: Example scheduling workloads
